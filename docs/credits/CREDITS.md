# Floor 13 credits and attribution

Floor 13 is an independent psychological survival-horror game. The game
code, original pixel art, procedural presentation, narrative, and mix work
are part of this project unless a source is listed below.

## Audio

Runtime audio is processed and mixed for the game. Source pages, creators,
licenses, and processing notes are recorded in
[`AUDIO_LICENSES.md`](AUDIO_LICENSES.md) and
[`docs/audio/THIRD_PARTY_AUDIO.md`](../audio/THIRD_PARTY_AUDIO.md).

Selected sources:

- [Scary Halloween](https://pixabay.com/music/scary-childrens-tunes-scary-halloween-617002/) — Dmitrii Spis (NastelBom), Pixabay Content License.
- [Dark Sci-Fi Audio Pack](https://opengameart.org/content/dark-sci-fi-audio-pack) — SRG774, CC0.
- [Lost in a Bad Place](https://opengameart.org/content/lost-in-a-bad-place-horror-ambience-loop) — congusbongus, CC0.
- [Echoes of the Past](https://opengameart.org/content/echoes-of-the-past) — isaiah658, CC0.

## Technology

The project uses Phaser, React, TypeScript, Vite, viem, wagmi, and the Hemi
network. Their own licenses and notices remain with the installed packages
and upstream projects.

## License notes

it does not permit redistributing an unmodified source as a standalone
